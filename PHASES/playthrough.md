Game starts and we are in the main menu. First button is "Fight", second button is "Roster", third button is "Competitive", fourth button is "Tips", and last button is "Exit Game". On the right top corner, there are two stats seen: "TP" - training points, and "XP" - experience points (usually x/y).
Clicking on "Fight": unavailable, until player enters "Roster" button and names units. After clicking, the battlefield is shown, HUD is shown, and "Battle starts! Please choose drop location" popup is shown. On HUD: on the top-center, there will be icon of a unit prefab alongside the number of alive units player has, which will together be a button. Clicking on this button shows player roster. On the top-left there will be "Turn: x". Right next to it will be "Alive: x", showing the number of alive units overall, no info on teams (allows players to self-track that info). Right under "Turn: x" tmp, there will be a fill bar, which fills with red. On its right there will be a tmp showing just number. The bar and tmp both signify the zone, and how many turns left till it starts shrinking. If the bar is filled, and the counter still goes down, that counter shows how many turns will the zone keep shrinking, until next phase starts. On the left-bottom corner, there will be blue circle button, which allows player to end turn. However, it will appear after turn 0, which is deployment. Popup message is a panel, which disappears only after player clicks on the screen, only after player can begin deployment selection. On the Roster Menu, there will be shown player units, their names, icons, and stats (current/max). Player can select drop location out of available nodes, then his units are presented on that node, Turn counter goes up one, first phase zone stopping square is shown, zone counter value changes, number of alive units also changes to 24, and blue end-turn button appears. Now player can command units and end turns. Units can be commanded by: selecting node on which there are player's units, Command Menu opens, units who are commanded selected, others unselected, after confirming that selection, the nodes on which those units can be sent are highlighted, player can click on any of them, and then ghost symbols of those units appear on both target node and current node (ghost symbols mean the same unit icons, but white, without team color). Clicking on their previous node, doesn't show them, but clicking on target node now shows them, and that menu is called Decision Menu. In Decision Menu deselecting units and confirming in reverse cancels that command for those units, returning them to the original node (deleting ghosts from target nodes, and turning ghosts into actual units on the original). After turn end is clicked only do the units move to the commanded position. However, it is possible to not give any command to units, and let them stay idle a turn. Some turn ends may trigger "Encounter", which is when player team happens to be on the same node as another team as the turn ends.

On top right there will be again TP and XP. On the right, there will be actual values of the stats, and the arrows will point to changed values, if level updated and points applied. Confirm is swipe up, Cancel is swipe down. On "Roster" menu, on the left-bottom, arrow to the left, circular button allows to get back to main menu.
Clicking on "Competitive": same as clicking on "Fight", but before immediately going into battle, opens "Roster" menu, with some number of TP already available to spend, and additional arrow-right button on the right-bottom to enter battle. But it would be unavailable initially (Competitive button).
Clicking on "Tips": will show list of buttons with titles describing game mechanics. Clicking on each opens up menu with description of the mechanic for players. At the open of this menu for the first time, one of such mechanic menus appears immediately, saying that all menus in the game can be swiped down, and sometimes swiped up, explaining what each does, and saying try to close this menu with swipe down. After closing it, it won't appear again, and player can browse through the tips, closing them with swipe down. The same right-arrow button appears here to exit to the main menu.
